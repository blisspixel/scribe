# Support

## Usage and installation help

Before opening an issue:

1. Read the [README](README.md), [CLI guide](docs/CLI.md), and
   [troubleshooting guide](docs/TROUBLESHOOTING.md).
2. Run `scribe doctor` for local diagnostics. Use `scribe doctor --live` only
   when you intentionally want provider connectivity checks.
3. Reproduce the problem with the smallest synthetic input you can create.
4. Search existing GitHub issues.

Use the bug-report issue form for reproducible defects and the feature-request
form for proposed changes. Scribe is maintained without a guaranteed response or
service-level agreement.

## Protect private data

Do not attach recordings, transcripts, API keys, `.env` files, logs containing
private content, or unreviewed support bundles. Redact usernames, paths, hostnames,
device identifiers, and provider request identifiers. Review the output of
`scribe support-bundle` before sharing it.

## Security and legal questions

Report vulnerabilities through [SECURITY.md](SECURITY.md), not a normal issue.
Questions about recording consent or legal compliance require qualified advice in
the relevant jurisdiction. Project support cannot determine whether a recording
or use is lawful or authorized.
